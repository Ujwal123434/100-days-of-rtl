# 🚀 100 Days RTL Design Challenge

Welcome to my **100 Days RTL Design Challenge**.

In this repository, I solve one RTL design problem every day using **Verilog HDL**. The goal of this challenge is to improve my RTL coding skills, strengthen my digital design concepts, and prepare for VLSI/FPGA interviews.

## 🛠 Tools Used

- Verilog HDL
- Icarus Verilog / Vivado Simulator
- GTKWave
- Visual Studio Code
- Git & GitHub

## 📂 Repository Structure

```
Day-01/
Day-02/
Day-03/
...
```

Each folder contains:
- RTL Design (`.v`)
- Testbench (`tb.v`)
- README with explanation


## 📈 Goal

- Improve Verilog coding skills
- Learn RTL design concepts
- Build a strong VLSI portfolio
- Prepare for RTL Design interviews
